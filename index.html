📌 О ПРОЕКТЕ

Проект «Умная теплица» — полностью автоматизированная система с облачной синхронизацией в реальном времени через GitHub Gist.


Функции:
• 📅 Годовой календарь
• 💡 Регулировка яркости
• ⚙️ Настройки автоматики
• 🔔 Push-уведомления
• 💾 Офлайн-режим
• 📈 Экспорт CSV
• 🌱 19 растений
• ☁️ Авто-синхронизация между устройствами (GitHub Gist)


Инструкция:
1. Создайте секретный Gist с файлом teplitsa.json
2. Создайте токен GitHub с доступом к gist
3. Перейдите в раздел "Настройки" и нажмите "Настроить"
4. Введите токен и ID Gist
